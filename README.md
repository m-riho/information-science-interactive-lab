# 立教大学「情報科学A」インタラクティブ教材

文系学生・高校「情報I」未履修者向けの、日本語のブラウザ教材です。フェーズ1（サイト基盤）・フェーズ2（回転円盤とFPS）と、フェーズ3（空間サンプリング・ローリングシャッター）を実装しています。メモリ階層とキャッシュ・ムーアの法則・論理ゲートも実装済みで、半加算器と4bit加算器を含む全7デモを利用できます。

## ローカルで使う

Node.js 24 LTSとnpmを推奨（`.nvmrc`）。

```bash
npm ci
npm run dev
```

表示されたURLをブラウザで開きます。

```bash
npm run typecheck
npm run test
npm run build
npm run preview
```

ビルド後のプレビューは `http://localhost:4173/information-science-interactive-lab/`。開発時のbaseは `/`、ビルド時は `/information-science-interactive-lab/` です。生成物はdist。

## できること

- 授業一覧 → 第3回 → 7デモのカード。円盤・空間サンプリング・ローリングシャッター・メモリ階層・ムーアの法則・論理ゲートが利用可能で、半加算器と4bit加算器を含む全7件が利用可能。
- Hash Routerによる直接リンク、更新、戻る・進む、未知URLの案内。
- 回転速度 −24〜24 rps、撮影fps 1〜60、再生速度0.1〜2倍。
- 正回転 / 静止 / 逆回転プリセット、開始/停止、1コマ送り、リセット。
- キーボード・タッチ操作、レスポンシブ表示、全画面、動きを減らす設定。
- 空間サンプリング：縞・格子・斜線・同心円、細かさ・位相・16〜256点の格子、最近傍/線形補間、標本化前ローパス。
- ローリングシャッター：Global/Rolling比較、回転速度・fps・読み出し時間・露光時間・走査方向、コマ送り。
- メモリ階層：LRUキャッシュ、順次/繰り返し/ランダムの48要求、ヒット率・ミス数・教育用の仮想待ち時間。
- 学習目標、各デモ3つの予想→操作→説明、展開式の数式。

## モデルと実装判断

- 1回転で元に戻る非対称マークを使用。実際の回転をr、撮影頻度をfとすると、見かけの回転は `r - f * floor(r/f + 0.5)`。範囲は `[-f/2, f/2)`。半周の境界では方向が曖昧で、表示は負側を採用します。
- 右の画像は `floor(t*f)/f` の撮影時刻の姿勢を保持。p5の描画ループとは独立です。露光ブラーはこのデモの対象外。
- 正値は時計回り。再生速度は模擬時間全体を伸縮し、rps表示は模擬時間基準です。
- 初期状態は停止。設定変更は時刻0へ戻します。リセットは1 rps・12 fps・1倍・停止に戻し、動きを減らす設定を維持します。
- 非表示タブでは描画と時間を停止。CanvasのpixelDensityを1、描画を最大60fpsに抑え、停止時は必要時のみ再描画します。
- 遷移でp5・イベント・ResizeObserverを破棄します。
- 公式スクールカラーは紫紺（DIC 226）。CSSのHEXはWeb用仮色で、公式RGB値ではありません。

## 空間サンプリングのモデル

- `src/demos/spatial-sampling/model.ts` が計算、`view.ts` がp5 instance modeの描画・操作を担当します。
- 縞は余弦波、格子は縦横の余弦波の平均、斜線は斜め方向、同心円は半径方向の余弦波です。基準画像は解析式から512 × 512で生成します。
- ローパスOFFでは各セル中心の明るさを解析式から直接読みます。ONでは内部画像に縦横の移動平均を3回適用し、その結果を標本化します。半径は `max(1, round(0.6 * 512 / N))`、端の外側は端の値を延長します。理想的な帯域制限ではなく、ガウス状の平滑化近似です。
- 表示補間は、標本値を変更せずCanvasの拡大方法を最近傍/線形で切り替えます。標本化前のローパスとは別工程です。
- 初期値は縞30周期・32点・位相0・ローパスOFF・最近傍・停止。プリセットとリセットは停止状態に戻し、動きを減らす設定は保持します。
- 位相を0.12周期/秒で変化させ、最大12fpsで描画します。停止中は変更時のみ再描画し、非表示タブでは描画と時間の進行を停止します。
- 小画面では基準画像自体にも表示上のモアレが起こり得ます。全画面と細かさの調整を案内しています。
- 直接リンクは `#/sessions/03/spatial-sampling`。HTMLをファイルとして直接開かず、devまたはpreviewサーバー経由で利用してください。

## ローリングシャッターのモデル

- `src/demos/rolling-shutter/model.ts` に数値計算、`view.ts` にp5の描画・操作を分離しています。
- 左は現在の仮想時刻における3枚羽の瞬間像、右は指定fpsのフレーム開始時刻を基準にした完成画像です。
- 上からの走査は `t_row = t_frame + row / height * readoutTime`。下からは `row` を `height - 1 - row` に置き換えます。Globalは全行同時刻です。
- 露光開始から露光終了までの9つの中点で明るさを平均します。露光0では瞬間像を計算します。高速回転・長時間露光では離散的な残像が出る近似です。
- 右は未来の行も含む完成画像を先に計算し、フレーム更新まで保持します。撮影完了までの待ち時間は再現しません。読み出し＋露光がフレーム間隔を超える設定も許す教育用モデルです。
- 初期値はRolling・3 rps・12 fps・読み出し60 ms・露光0 ms・上→下・停止。回転速度は−12〜12 rps、fpsは1〜30、読み出しは0〜80 ms、露光は0〜30 ms。
- 方式と方向の切替は時刻を保持、数値変更は時刻0に戻します。Globalでは読み出し・方向を無効表示します。リセット・プリセットは停止に戻し、動きを減らす設定を維持します。
- 最大24fps、計算画像192 × 192で負荷を抑制。同一フレームの撮影結果を再利用します。非表示時に停止し、遷移時はp5・Observer・イベントを破棄します。
- 3枚羽の周期は1/3回転です。円盤の1回転周期と区別し、見かけの回転数を流用しません。フレーム間のエイリアシングと1枚のローリング歪みを別々に説明します。
- 直接リンクは `#/sessions/03/rolling-shutter`。

## メモリ階層とキャッシュのモデル

- `src/demos/memory-hierarchy/model.ts` に純粋なLRU計算と要求列生成、`view.ts` に描画・操作を分離しています。
- 1段の全相連想・読み出し専用キャッシュ。1ブロックは4データ、容量は1〜8ブロック。最近使用した順で保持し、満杯時は末尾のLRUを追い出します。ヒットでも使用順を更新します。
- アドレス0〜31はすでにRAMにある前提です。SSDは保存先として図示し、この要求列では読みません。レジスタはCPUが使う取得データを示す概念図で、ヒット率計算の対象ではありません。
- 待ち時間は教育用の仮想値。キャッシュ確認1単位、RAM読み出し追加10単位。総待ち時間は `ヒット数 + ミス数 * 11`。実測値や実機の性能比ではありません。
- 各列は48要求。順次は0〜31の循環、繰り返しは0,4,8,12の循環、ランダムは固定シード2026の疑似乱数。容量を変えても同じ要求列で比較できます。
- 初期値は繰り返し・容量4・速度1倍・停止。容量とパターン変更で空キャッシュからやり直し、速度変更は状態を保持。リセットは初期値に戻し、動きを減らす設定は維持します。
- 統計とLRU順は要求の完了時に更新。停止は処理中の要求を保持、1要求送りは処理中の要求があればそれを完了します。48件完了時は自動停止します。
- 再生は最大30fps、1要求あたり1.6秒/再生倍率。アニメーションの長さは仮想待ち時間の比率を表しません。非表示時は停止し、遷移時に描画・イベントを破棄します。
- 読み書きの競合、多段キャッシュ、プリフェッチ、ページングなどは扱いません。
- 直接リンクは `#/sessions/03/memory-hierarchy`。

## ムーアの法則のモデルとデータ

- `src/demos/moores-law/data.ts` に代表値・出典、`model.ts` に指数モデル・軸変換、`view.ts` にp5描画を分離しています。
- 代表値はIntel 4004（1971年・2,300個）、80386 DX（1985年・275,000個）、Core i7-920（2008年・731,000,000個）、Apple M2 Ultra（2023年・134,000,000,000個）。
- **仕様書との差**：80386の約229,000個、初期Core i7の約3.8億個は、[Intel公式表](https://www.intel.com/pressroom/kits/quickreffam.htm)に基づいて上記の型番・値に修正しました。元の仕様書は保存しています。
- M2 Ultraは[Appleの発表](https://www.apple.com/newsroom/2023/06/apple-introduces-m2-ultra/)に基づく2ダイSoC。CPUとの混在・同条件比較ではないことを明記します。
- モデルは `2300 * 2 ** ((year - 1971) * 12 / months)`。12/18/24か月を同じ起点で比較します。データへの回帰・将来予測・処理性能のモデルではありません。
- 対数軸（下端1,000個）／通常軸（下端0）を切替。軸上限は表示モデルの2050年の値と全代表値を含むように設定し、年スライダーでは固定します。モデル切替時は上限が変わります。
- 初期状態は2050年・対数軸・24か月だけ表示・停止。開始で1971年から約4年/秒で再生し2050年で停止。途中で停止した場合はその年から再開。年スライダーの操作で停止します。
- 線の種類と色でモデルを区別し、代表データは番号付きの点と表で表示します。比較表は年スライダーに関係なく全期間を掲載します。
- 1965年の約1年、1975年の約2年、通俗的な18か月表現を区別します。歴史と性能についての出典も画面に掲載。
- 直接リンクは `#/sessions/03/moores-law`。非表示タブで停止、動きを減らす設定ではスライダーで操作、遷移時にp5・Observer・リスナーを破棄します。

- 期間を2050年まで延長。代表データは2023年までに留め、それ以降を背景色と「仮定の延長」で区別します。物理的限界や実現可能性を織り込んだ将来予測ではありません。

## 論理ゲートのモデル

- `src/demos/logic-gates/model.ts` に真理値とNAND構成、`diagram.ts` に配線・スイッチ図、`view.ts` に操作を分離しています。
- AND・OR・NOT・NAND・XORの入力を切り替え、ランプと真理値表を同期。NOTではBを使用しません。
- NANDのみでNOT（1個）・AND（2個）・OR（3個）を構成し、中間出力を手動または1秒ごとの自動再生で確認します。段階表示は説明用の計算順で、実際の伝播時間ではありません。
- 直列・並列スイッチは通り道を示す自作の概念図。実際のトランジスタ回路を表しません。
- 入力変更は全段階の中間値と出力に即時反映し、「最初から再生」で計算順を確認できます。回路変更は段階を初期化。リセットは基本AND・入力0/0に戻し、動きを減らす設定は維持します。非表示時は再生を休止し、画面遷移時に描画・イベントを破棄します。
- 直接リンクは `#/sessions/03/logic-gates`。

## 半加算器と4bit加算器

- `#/sessions/03/binary-adder`。半加算器はSUM=XOR、CARRY=AND。全加算器は半加算器2個とORで計算します。
- 4bitは符号なし0〜15、Cin初期値0、結果を5bitと十進数で表示。入力は二進数のビットボタンで切り替え、完成値に即時反映します。入力の十進数値は表示のみです。

- 自作SVGとHTMLで描画。狭幅では1の位から縦に並べます。非表示タブではタイマーを止め、復帰時から次の桁を待ちます。動きを減らす設定では手動送りを使います。遷移時はタイマーとイベントを破棄します。
- リセットは半加算器・0+0、動きを減らす設定は保持。プリセットは半加算器で1+1、4bitで7+1です。
