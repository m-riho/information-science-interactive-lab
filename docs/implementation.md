# フェーズ1・2の設計と実装計画

対象は初学者向けの日本語教材。仕様は prompts/codex_rikkyo_information_science_demos.md。

1. Vite + strict TypeScript、p5 instance mode、Hash Router、紫紺テーマを構築する。
2. セッションのメタデータから7カードを表示。円盤以外は準備中ページにする。
3. 円盤の計算を純粋関数として分離し、静止・逆回転・負回転・境界・撮影時刻をテストする。
4. 円盤に1回転周期の非対称マークを描き、基準とサンプル保持画像を比較する。
5. HTML操作パネル、問い、数式、全画面、動きを減らす設定、破棄処理を実装する。
6. 日本語ドキュメントとPages workflowを作成し、型・単体テスト・ビルド・ブラウザ操作を確認する。

描画はp5のrequestAnimationFrameベースのループ。撮影時刻は floor(t × fps) / fps。
見かけの回転数は [-fps/2, fps/2) に折り返す。ちょうど境界では方向が一意に決まらない。
パラメータ変更時は時刻を0に戻して途中での位相不連続を避ける。再生速度は仮想時間全体に作用。
ルート変更でp5.remove、ResizeObserver、イベントリスナーを破棄する。非表示タブではループ停止。
公開・push・リモート設定は実施しない。実装後はフェーズ2で停止する。
