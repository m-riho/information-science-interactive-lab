# 情報科学A 第7回：実装方針

仕様：prompts/codex_A07_interactive_demos_14.md

## 構成
既存のVite + TypeScriptプロジェクトのindex.htmlとHash Routerを使い、入口は#/sessions/07とする。JavaScript 10本とNotebook 4本の順序・対応スライド・学習目的はsrc/sessions/session07.tsに集約する。各教材はその配下の直接リンクで開く。既存Session 03〜06のURLを維持する。

独立した静的HTMLサイトを別に作る案に比べ、共通レイアウト、紫系テーマ、前後リンク、操作部品、破棄処理を既存実装に合わせられるため、この構成を採用する。計算は純粋なmodel.ts、画面はview.tsに分ける。Notebook本体・必要ライブラリの固定・Colabリンク・実行済み出力はPhase 4で追加する。

## フェーズ
1. 共通基盤：授業一覧の入口、14件の一覧・準備中ページ、共通表示、ルートとナビゲーションの検証。
2. JS04・05・01・08：重み付き和、パーセプトロン、k-means、過学習。
3. JS02・03・06・07・09・10：強化学習、MCTS、活性化関数、XOR学習、混同行列、ショートカット学習。
4. 実行済みNotebook 4本と環境・参考資料。モデル重みや画像の配布条件も確認する。
5. 操作・アクセシビリティ・レスポンシブ・数値計算・既存教材の回帰と公開用ファイルの確認。

Phase 1は計算・学習・Notebookを実装しない。利用可能に見えるリンクや仮のColab URLを置かない。操作コールバックがない再生・リセットボタンは共通操作部品で無効化する。

## 数値・教育上の注意
- 第6回のしきい値は z >= 0、第7回の指示書は s > 0。第6回のneuron関数の動作を変更せず、第7回のモデルで明示する。
- JS05は初期(1,1,-0.5)、入力(1,0)、正解0、学習率1で(0,1,-1.5)への更新を検証。
- 非線形な多層化による表現と、自動学習の違いを説明。
- 各乱数を固定・再現可能とし、探索・学習・描画に上限を設ける。離脱・非表示・動きを減らす設定で再生を止める。
- 安定した最小二乗、検証用データとテストデータの役割、分母0の指標を確認。
- Notebookは実行結果を保存。CPUのみでも完走させる。GPU未検証なら未検証と明記。
