## 数値と表現の位置づけ

JS01は `js-tiktoken 1.0.21` の `o200k_base` を同梱し、ブラウザ内でBPEを計算する。スライド9のPython `tiktoken 0.12.0` と日本語14トークン・英語4トークンのIDを照合し、同じPython版で絵文字・補助漢字のIDも再計算した。トークン27113の e5 82 と246の98は各々不完全なUTF-8なので、置換文字で表示せず元バイトを示す。公開rankデータのbase64列からバイトを取り出し、`TextDecoder`のfatalモードで判定する。入力上限はUTF-16で1000コード単位。特殊トークン風の文字列も普通の文字列として分割する。語彙はJS01を開いたときだけ遅延読込みする。ライブラリはMITライセンス。[js-tiktoken](https://github.com/dqbd/tiktoken/tree/main/js)・[OpenAI tiktoken](https://github.com/openai/tiktoken)

JS02の分布と語句単位の分割は教材用の模式例。LLMは実行せず、候補分布は有限の分岐として与える。最終の句点に続くEOSで終了する。抽選はブラウザで実行する。

JS03の入力確率は架空値、温度変換と抽選は実計算。`log(p)`から最大値を引いて指数化することで、小さい温度でも数値を安定させる。T=0を計算しない。全件集計と表示用の最新24回履歴を分ける。低温も高温も内容の正確性を保証しない。

JS04は指示書の任意機能から2次元模式図のみを採用。座標は実測したEmbeddingではなく、点を動かす操作は学習ではない。実モデルの高次元ベクトル・PCAモードは実装していない。図の距離だけで意味のすべてを表すとは説明しない。

JS05のq=(1,0)、k太郎=(0,1)、k花子=(1,0)、k本=(0.5,0.5)は教材用に直接指定する。スライド25〜27の架空重み0.2/0.7/0.1と異なり、このデモはscaled dot-productの結果を計算して表示する。初期重みは約0.2246/0.4555/0.3199。Vは太郎=(1,0)、花子=(0,1)、本=(1,1)で固定、出力は約(0.5445,0.7754)。学習行列WQ/WK/WVと、その場で計算するAttentionの重みを区別する。出力は単一ヘッドの重み付き和であり、代名詞解決・残差接続・Transformer全体の再現は含まない。

JS06は「今日／は／雨／です」の模式分割。4×4行列の○は参照の許可で、重みの大きさではない。最終行より先の正解は提示していないので、「です」の行では未提示と表示する。対象はDecoder-onlyのcausalなAttention。

JS07も模式分割。文頭の特殊記号を省略し、入力が1単位以上ある9境界から学習例を作る。正解以後を入力へ漏らさない。パラメータの学習は行わない。

JS08の図書館案内はすべて架空。検索は固定質問の話題タグ照合で、回答は条件分岐で選ぶ事前作成文。旧版Bと新版Dは適用日が異なる。通常日／試験期間／臨時休館の条件と、出典に書かれた内容を確認する。駐車場の質問では検索0件、根拠なしを表示する。出典があっても誤読した例を比較できる。

## 実装・運用

各デモは `src/demos/<slug>/model.ts` に計算、`view.ts` にDOMと操作を配置する。`src/demos/llm-common` はレイアウト・確率棒グラフを共有する。メタデータと一覧は `src/sessions/session08*.ts`、ルートは `src/utils/router.ts` と `src/main.ts`。状態はページ内のみで保持する。イベントは破棄時に解除、自動実行は初期停止・自然終了・タブ非表示・動きを減らす設定で停止する。

```sh
npm ci
npm run dev
npm run typecheck
npm run test
npm run build
npm run preview -- --host 127.0.0.1 --port 4175
```

開発サーバーは `/#/sessions/08`、本番プレビューは `/information-science-interactive-lab/#/sessions/08`。
起動中に `npm ci` で依存関係を再構築した場合は、開発サーバーも再起動する。必要なら `npm run dev -- --force` で依存キャッシュを更新する。
