# Universal Approximation Implementation Plan

**Goal:** 第7回へ構成と学習を区別するJS11を追加する。
**Architecture:** 純粋な数値モデル、SVG描画、共通操作を使用。Hash Routerへ統合し静的入口も配置。
**Tech Stack:** TypeScript / Vite / Vitest / SVG、追加依存なし。
**Spec:** `docs/universal-approximation.md` およびユーザー指定作業指示書。

## Global Constraints
- 既存14教材のURLと数理モデルを維持。実際のReLU数をNとする。
- 構成は学習と呼ばない。有限グリッドの最大値はsupと呼ばない。
- 初期停止、変更時初期化、非表示停止、タイマー・イベント破棄、320pxとキーボード対応。

## Review Focus
- N=2/32・端点・|x|の偶奇による折れ目の違い。
- 学習率.1と大きなシードでも有限値、上限で確実に停止。
- モード変更・連打・再実行でタイマーが重複しない。
- 未使用評価点が訓練点や勾配へ入らない。
- 静的入口がサブパスで正規URLへ移動する。
