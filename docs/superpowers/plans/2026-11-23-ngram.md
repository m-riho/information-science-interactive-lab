# n-gram教材 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 第8回に単語単位n-gramの抽出・頻度・生成・限界を体験する4タブの教材を追加する。

**Architecture:** 純粋なmodel.tsで行単位の抽出・頻度表・予測・有限生成を扱う。view.tsは既存mountLlmと共通操作を再利用し、SVG棒グラフ・キーボード対応タブ・確認問題を描画する。

**Tech Stack:** TypeScript / Vite / Vitest / HTML / SVG。依存追加なし。

**Spec:** prompts/codex_A08_ngram_interactive_demos_08.md

## Global Constraints
- n=1〜5、初期3。空白区切り、1行1文、文境界を越えない。
- EOSを通常単語と区別し、開始文込みで最大30単語。未知文脈と文脈不足を区別して停止。
- 既存12教材のURL・動作を維持。番号の衝突は既存を維持するJS13で解決。質問への回答はなく、推奨方針を明示して実装した。
- 学習編集は再学習で確定。n変更は確定済みデータから再構築。生成を初期化。
- 非表示・タブ切替・設定変更・離脱で自動生成停止。動きを減らす設定を維持。
- 公開・pushは今回行わない。現在のチェックアウトを利用する。

## Review Focus
- 空入力・nより短い文・長い開始文・改行/全角空白。
- ユーザー入力のHTML注入、終了記号に似た文字列との衝突。
- EOSを含む正規化、n=1の空文脈、同率時の選択。
- タブ移動と自然終了時のフォーカス、タイマー破棄。
- サブパス直接リンク・スマホ幅・既存教材の回帰。
