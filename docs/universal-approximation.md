## 数理仕様とN

モデルは1入力→N個のReLU→線形出力。`F(x) = c + Σ aᵢ max(0, wᵢx + bᵢ)`。

構成モードでは区間[L,R]をN等分し、N+1節点 `t₀,…,t_N` における目標関数を補間する。区間の傾きを `m_j=(f(t_{j+1})−f(t_j))/(t_{j+1}−t_j)` とすると、

`F(x)=f(L)+m₀ ReLU(x−L)+Σ(j=1…N−1)(m_j−m_{j−1}) ReLU(x−t_j)`。

範囲内で `ReLU(x−L)=x−L`。境界用1個＋内部の折れ目用N−1個＝実際のReLUユニットN個。出力係数が0のユニットもモデルに含め、その値を表で確認できる。N=2〜32、初期8。目標はsin(x)（−π〜π）、x²と|x|（−1〜1）。表示曲線は補間関数を別描画せずネットワーク出力を評価する。範囲外への近似保証はない。

学習モードは同じ構造のw,b,a,cを全て更新する。シード7を既定にLCGで初期化。訓練点32個は端点を含む等間隔、未使用評価点124個は各訓練区間内の4点（訓練点と重ならない）。訓練点のMSEに対する全バッチAdam（β₁=.9、β₂=.999、ε=10⁻⁸）、ReLUの0での微分は0。勾配ノルム上限10。学習率.001〜.1、初期.01。1ステップは1回更新、自動実行は100ms毎に25回、最大5000更新（初期2000）。数値異常時は直前の有限状態で停止し理由を表示する。設定変更は停止して学習を初期化、リセットは全設定を既定へ戻す。非表示・動きを減らす変更・離脱で停止しタイマー解除。

## 誤差と教育上の注意

表示用401等間隔点でMSEと最大絶対誤差を別表示する。最大値は有限点の測定で数学的なsupや上界ではない。学習モードは訓練MSE・未使用評価MSE・訓練損失履歴も表示する。評価点は勾配計算・停止判定へ使わない。条件を比較して選ぶ場合は検証データに相当し、最終テストではない。

適切な活性化関数・ネットワーク構成の下で、コンパクト集合上の連続関数を任意の精度で一様近似するパラメータが存在する。ここでは1次元区間の連続関数について折れ線構成を観察する。有限グリッドの実験は定理の証明ではない。固定Nの万能性、不連続関数の一様近似、学習成功、汎化性能を保証しない。N変更時の実測誤差を示し、単調改善とは説明しない。構成は訓練ではない。
