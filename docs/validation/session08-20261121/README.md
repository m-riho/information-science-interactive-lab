## ブラウザ検証の再実行

```sh
npm run build
npm run preview -- --host 127.0.0.1 --port 4178 --strictPort
# 別のターミナルで（必要なら PLAYWRIGHT_PACKAGE を指定）
node scripts/check_session08_browser.mjs
```
