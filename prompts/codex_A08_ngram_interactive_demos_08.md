# 5. タブ1：n-gramの抽出

## 目的

n-gramが、連続するn個の単語から構成されることを理解させます。

## 初期文章

```text
今日 は 雨 が 降って います
```

## 機能

nを変更すると、抽出されるn-gramを即座に更新してください。

### n=1

```text
今日
は
雨
が
降って
います
```

### n=2

```text
今日 は
は 雨
雨 が
が 降って
降って います
```

### n=3

```text
今日 は 雨
は 雨 が
雨 が 降って
が 降って います
```

### 可視化

文章を横方向に表示し、n個の単語を囲む枠を描いてください。

「次へ」をクリックすると、枠が1単語ずつ右へ移動します。

対応するn-gramを画面下部に表示してください。

### 追加機能

抽出されたn-gramの一覧と、その出現回数を表示してください。

同じn-gramが複数回現れた場合は、出現回数を合計してください。

# 6. タブ2：出現頻度と確率

## 目的

n-gram言語モデルが、学習データ中の出現頻度から次の単語の確率を推定することを理解させます。

## 初期学習データ

```text
今日 は 雨 が 降る
今日 は 雨 が 強い
今日 は 雨 が 降る
今日 は 雪 が 降る
```

1行を1つの文章として扱ってください。

文章をまたいでn-gramを抽出しないでください。

## 初期設定

n=3

直前の2単語：

```text
雨 が
```

## 計算

次の単語の出現回数を数えます。

| 次の単語 | 出現回数 | 確率 |
|---|---:|---:|
| 降る | 2 | 2/3 |
| 強い | 1 | 1/3 |

確率は、次の式で計算してください。

\[
P(w_i\mid w_{i-n+1},\ldots,w_{i-1})
=
\frac{C(w_{i-n+1},\ldots,w_i)}
{C(w_{i-n+1},\ldots,w_{i-1})}
\]

ここで、Cは出現回数です。

## 機能

- nの変更
- 直前の単語列の選択
- 次の単語の出現回数
- 確率の計算結果
- 確率分布の棒グラフ
- 学習データの編集
- 再学習ボタン

### 重要事項

確率は、学習データから実際に計算してください。

説明用の固定値を表示するだけの実装にはしないでください。

### 未知の文脈

学習データに存在しない文脈を入力した場合は、

「この文脈は学習データに存在しないため、単純な頻度推定では次の単語を予測できません」

と表示してください。

確率を0で割る処理は行わないでください。

# 7. タブ3：n-gramによる文章生成

## 目的

n-gramモデルでも、次の単語を予測して文章を生成できることを理解させます。

## 機能

- 生成開始文の指定
- 次の単語の確率分布表示
- 最大確率による選択
- 確率に従うサンプリング
- 1ステップ生成
- 自動生成
- 一時停止
- 初期化

## 生成処理

1. 現在の文章から直前のn−1単語を取り出す。
2. 学習データから、その文脈に続く単語の確率を計算する。
3. 選択方式に従って次の単語を選ぶ。
4. 選んだ単語を文章に追加する。
5. 次の予測を繰り返す。

## 最大生成長

最大30単語としてください。

無限ループを防いでください。

## 文章の終了

各行の終端に、内部的な終了記号を追加してください。

終了記号が選ばれた場合は生成を停止してください。

終了記号は通常の単語として表示しないでください。

## 初期文

```text
今日 は 雨 が
```

## 重要事項

学習データの頻度に従って文章を生成してください。

あらかじめ用意した完成文章を選ぶだけの実装にはしないでください。

また、nが大きい場合には、学習データにない文脈で生成が停止することがあります。

その場合は、理由を画面に表示してください。

# 8. タブ4：n-gramの限界

## 目的

n-gramモデルが参照する文脈の長さと、学習データの不足による問題を理解させます。

## 機能1：文脈長の比較

同じ文章について、nを変更してください。

例えば、

```text
太郎 は 昨日 図書館 で 花子 に 会った
```

n=2では直前の1単語、n=3では直前の2単語を参照します。

nを大きくすると、より長い文脈を参照できることを可視化してください。

## 機能2：未知の文脈

学習データに存在しない単語の並びを入力すると、予測できなくなることを表示してください。

## 機能3：nによる比較

以下を比較してください。

- 参照する単語数
- 学習データに存在する文脈の数
- 予測できる文脈
- 予測できない文脈

## Transformerとの比較

以下の表を表示してください。

| 観点 | n-gram | Transformer型言語モデル |
|---|---|---|
| 次の単語の予測 | 可能 | 可能 |
| 文脈 | 直前のn−1単語 | 文脈長の範囲 |
| 予測方法 | 出現頻度など | 学習した数値表現 |
| 離れた情報 | 扱いにくい | Attentionなどで扱える |

Transformerでも、長い文脈を常に正しく利用できるわけではないことを明記してください。

# 13. 最終的な教育方針

このデモでは、学生が次の3点を理解できることを重視してください。

1. n-gramは、連続する単語の組を利用する。
2. 出現頻度から次の単語の確率を計算できる。
3. n-gramでも文章生成はできるが、参照できる文脈や未知の単語列への対応に限界がある。

また、n-gramとLLMは、**次の単語・トークンを予測するという基本的な考え方を共有している**ことを示してください。

一方で、Transformer型LLMは、単純なn-gramの頻度表とは異なる方法で文脈を処理することを明確にしてください。

以上の方針で、既存の第8回教材に統合できるインタラクティブデモを制作してください。
