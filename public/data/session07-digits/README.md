# 手書き数字「1」と「それ以外」

## データの出典と利用条件

MNIST（Yann LeCun、Corinna Cortes、Christopher J. C. Burges）の28×28画素の手書き数字を使用した。MNISTはNISTのデータから作られた。著作権者はYann LeCunとCorinna Cortes。本教材の画像・ラベルのサブセットも同じCC BY-SA 3.0で配布する。[Kerasによるデータとライセンスの説明](https://keras.io/api/datasets/mnist/)・[CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/)

元の訓練60,000枚とテスト10,000枚から、それぞれ独立に固定シードで重複なく抽出した。変更は画像の選択・並べ替え・ファイル形式の変換で、画素値と元の数字ラベルを維持した。[配布元のmnist.npz](https://storage.googleapis.com/tensorflow/tf-keras-datasets/mnist.npz)・[Kerasが公開するSHA-256](https://github.com/keras-team/keras/blob/master/keras/src/datasets/mnist.py)

| 用途 | 抽出数 | 数字1 | それ以外 | 抽出シード |
| --- | ---: | ---: | ---: | ---: |
| 訓練 | 2,000 | 1,000 | 1,000 | 7071 |
| テスト | 500 | 250 | 250 | 7072 |

数字1の画像と、それ以外の画像を交互に格納した。負例の数字は0、2、3、4、5、6、7、8、9を順に選ぶ。訓練の先頭200枚・1,000枚、テストの先頭100枚でも二値ラベルの比率は1対1になる。元のMNIST全体では数字1の比率が異なるため、正解率はこの抽出条件での成績として読む。

## 再生成

Python 3とNumPyが使える環境で、リポジトリ直下から次を実行する。配布物の生成に使用したNumPyは2.4.6。

```sh
python3 scripts/prepare_session07_digits.py
```

取得済みなら `--source /path/to/mnist.npz`、別の保存先を使う場合は `--output /path/to/output` を指定する。公式アーカイブのSHA-256を検証してから展開する。

`train.bin` と `test.bin` は、先頭に各画像の元の数字ラベルを1バイトずつ並べ、続いて同じ順序で画像を格納する。画像は左上から行順に784バイト（0が黒、255が白）。モデルに渡すときは画素値を255で割る。

## 学習済みの例

`pretrained.f32` は本教材用に訓練2,000枚から生成した。784入力 → 32ユニット（ReLU）→ 1出力（Sigmoid）のネットワークで、損失関数は二値交差エントロピー。シード7073を使って重みを初期化し、各エポックで訓練順をシャッフルした。ミニバッチSGDで学習率0.1、バッチサイズ32、3エポックとした。更新にテスト画像は使用しない。

重みファイルはリトルエンディアンfloat32。入力×隠れ層の重み（784×32、行優先）、隠れ層バイアス32個、出力層の重み32個、出力バイアス1個の順に格納する。しきい値0.5でテスト500枚を判定した配布モデルの結果は、真陽性246、偽陰性4、真陰性248、偽陽性2。正解率は98.8%、数字1の再現率は98.4%。
